Scrimba Code Notes

This project is just all the notes I took while in the Scrimba Front-end Career Path. These notes include but are not limited to Vanilla JS, CSS, Accessiblity, and React JS. I am especially proud of the unnecessary but very entertaining lengths I went to with the CSS.

Project Overview

The most challenging part of this project was honestly the notes I took. I tried to keep them in depth, but clear. The goal was to solidify the learned information in my mind by re-writing the information. I did however struggle particularly with using regex for the search bar, as that was my first real-world introduction to regex.

Making the pencil using pure CSS was also nothing to sneeze at. While CSS is my strongest language, as when I was a WordPress developer, most of the work I did was customizing already created themes using CSS, making a pencil was a challenge I had yet to meet. I am very proud of the results. Also note the sticky note at the top! So cute right?
